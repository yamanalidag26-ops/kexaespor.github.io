# KEXA ESPOR — GitHub Pages + Admin Panel

## Dosyalar
- `index.html` — ana site
- `admin.html` — admin panel
- `style.css` — tasarım
- `script.js` — site verilerini gösterir
- `admin.js` — admin işlemleri

## Admin
Ana sitenin en altındaki `ADMIN` bağlantısından panele girilir.

Demo şifre: `KEXA2026`

### ÖNEMLİ
Bu sürüm GitHub Pages üzerinde çalışması için **localStorage** kullanır. Yapılan değişiklikler yalnızca admin işlemini yaptığın tarayıcıda saklanır; başka ziyaretçilerin ekranına otomatik olarak gitmez.

Gerçek, herkes için ortak çalışan güvenli bir admin paneli için daha sonra ücretsiz bir backend/veritabanı (ör. Supabase/Firebase) bağlanmalıdır.
